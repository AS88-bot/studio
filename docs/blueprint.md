# **App Name**: SignText Converter

## Core Features:

- Signature Upload: Allow users to upload their signature image in common formats (e.g., PNG, JPG).
- Signature to Text Conversion: Employ AI to analyze the signature image and convert it into editable text format.
- Text Export: Enable users to copy and paste or download the converted text signature.
- Note Upload and Sharing: Let users upload text notes and generate a secure, unique URL to share with others. Use a tool to evaluate the best context for formatting the content of the notes.
- Text-to-Handwriting Conversion: Use generative AI to transform plain text into realistic-looking handwriting. Offer customization options for handwriting style (e.g., font, slant, thickness).

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) for a calming and professional feel.
- Background color: Light gray (#F5F5F5) for a clean, non-distracting backdrop.
- Accent color: Dusty rose (#D8BFD8) for interactive elements and highlights.
- Font pairing: 'Belleza' (sans-serif) for headings, 'Alegreya' (serif) for body text.
- Use simple, line-based icons for intuitive navigation.
- Maintain a clean, minimalist layout with plenty of white space to enhance readability.
- Incorporate subtle transitions and animations to provide a smooth user experience.
