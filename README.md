🧠 Studio – Smart Handwriting & Notes Exchange Platform

Studio is an all-in-one web application that combines AI handwriting recognition, text-to-handwriting generation, and peer notes exchange into one seamless experience.
Built to simplify digital note-taking and personalization, Studio lets users share notes, digitize their handwriting, and create authentic handwritten text — instantly.

🚀 Features
✍️ 1. Handwriting to Text Converter

Upload handwritten notes or signatures.

AI extracts and converts handwriting into editable, digital text.

🖋️ 2. Text to Handwriting Generator

Upload your handwriting sample or signature once.

The app learns your writing style and converts typed text into your personalized handwriting.

📚 3. Peer Notes Exchange

Share, browse, and download notes uploaded by peers.

Supports both handwritten and digital notes.

Encourages collaboration and quick learning in real-time.

🧠 Tech Stack
Layer	Technology
Frontend	React.js, Tailwind CSS, Framer Motion, Radix UI
Backend	Flask, Flask-CORS, Python
AI / Processing	OpenCV, NumPy, Pillow, Tesseract OCR
Database (optional)	Firebase / MongoDB (if used for notes storage)
Version Control	Git & GitHub

⚙️ Installation & Setup

🔧 Backend Setup
cd backend
pip install -r requirements.txt
python app.py

💻 Frontend Setup
cd frontend
npm install
npm start
